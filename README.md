# 🏃 RunQ (런큐)

**달리면, 여행이 된다. — 강릉 러닝 코스 추천부터 완주 후 맛집·카페·볼거리까지 하나로 잇는 런트립 큐레이션 앱**

RunQ는 강릉의 바다·호수·해안 산책로를 따라 달리는 러닝 코스를 추천하고, 완주 지점(Finish Hub) 주변의 맛집·카페·볼거리를 이어서 추천하는 Android 앱입니다. 한국관광공사 TourAPI, 기상청, 에어코리아 공공데이터와 RunQ가 직접 조사한 로컬 큐레이션 데이터를 결합해, 러닝이 곧 지역 여행이 되는 경험을 만듭니다.

> 2026 관광데이터 활용 공모전 **웹·앱 개발 부문** 출품작 · 팀 **D-Node** (2인)

## 프로젝트 개요

### 배경

- 러닝이 대중적인 여가문화로 자리 잡으면서, 러닝과 여행을 결합한 **'런트립'** 에 대한 관심이 커지고 있습니다.
- 하지만 여행지에서 러닝을 계획하려면 코스, 날씨, 편의시설, 주변 관광지 정보를 여러 플랫폼에서 따로 찾아야 합니다.
- 강릉은 경포호·안목해변·강문해변 등 달리기 좋은 자연환경과 풍부한 로컬 관광자원을 함께 갖춘 도시입니다.

### 목표

- 관광데이터를 활용해 **맞춤형 러닝 코스**와 **러닝 후 주변 맛집·카페·관광지**를 한 흐름으로 추천
- 날씨·미세먼지·바람 정보로 **오늘 달려도 되는지**를 한눈에 판단
- 러닝 기록을 지역 체류와 소비로 이어지게 해 **지역 관광 활성화**에 기여

### 차별성

| 항목 | 기존 러닝 앱 | RunQ |
| --- | --- | --- |
| 서비스 범위 | 코스 안내 · 기록에서 종료 | 완주 후 지역 관광까지 잇는 **After-run 경험** |
| 데이터 | 사용자 기록 위주 | **관광공사 · 기상청 · 에어코리아 공공데이터 + 자체 로컬 큐레이션** |
| 지역성 | 전국 단위, 범용 코스 | **강릉 집중**, 전국 서비스가 놓치기 쉬운 로컬 코스·장소 |
| 러닝 후 동선 | 사용자가 직접 검색 | **Finish Hub** 기준 EAT · CAFE · SEE 자동 추천 |

## 주요 기능

- **러닝 코스 탐색** (`Course` 탭) — 거리(3km / 5km / 10km+)·난이도·지형 조건으로 강릉 코스를 필터링하고, 코스 상세에서 거리·예상 시간·경관 정보를 확인
- **실시간 GPS 트래킹** (`Run` 탭) — 지도 위에서 현재 위치·거리·시간·페이스·칼로리를 실시간으로 확인, 종료 후 완주 기록 요약
- **Finish Hub** (`Place` 탭) — 완주 지점 주변 **EAT · CAFE · SEE** 장소를 지도와 리스트로 추천, 거리순/추천순 정렬, 상세 정보 확인 후 저장하거나 "여기로 달리기"로 다음 목적지 지정, 카카오맵 길찾기 연동
- **강릉 행사·축제** (`Place > 행사`) — 진행 중이거나 예정된 강릉 지역 축제 안내
- **오늘의 러닝 환경** (`Home`) — 기온·미세먼지·풍속·강수 정보와 이를 종합한 **러닝 적합도** 표시
- **러닝 기록 관리** (`MY`) — 완료한 러닝 목록, 이동 경로·거리·시간·평균 페이스 상세 조회
- **저장 · 검색 · 알림** — 코스와 장소 저장, 키워드로 코스·장소 통합 검색, 주간 러닝 리포트·추천 코스·누적 러닝·Finish Hub 추천 알림

## 데이터 활용

### 한국관광공사 OpenAPI

| # | API | 활용 |
| :-: | --- | --- |
| 1 | TourAPI(KorService2) – 위치기반 관광정보조회 `locationBasedList2` | Finish Hub 좌표 기준 반경 내 음식점·카페·관광지를 조회해 자체 큐레이션과 결합한 추천 리스트 구성 |
| 2 | TourAPI(KorService2) – 관광정보 상세조회 `detailCommon2` | 장소 상세 화면의 주소·개요·대표 이미지 제공 |
| 3 | TourAPI(KorService2) – 행사·축제 정보조회 `searchFestival2` | 강릉에서 진행 중이거나 예정된 행사·축제 안내 |

### 기타 API · 데이터

| # | 데이터 | 활용 |
| :-: | --- | --- |
| 1 | Kakao Maps SDK v2 · Kakao Local API | 지도 표시, 러닝 코스 경로와 START/FINISH 위치 시각화, TourAPI에서 부족한 카페 정보 보완 |
| 2 | 기상청 단기예보 – 초단기실황 `getUltraSrtNcst` | 강릉(격자 nx=92, ny=131)의 실시간 기온(T1H)·강수(RN1)·풍속(WSD) 조회 |
| 3 | 한국환경공단 에어코리아 – 시도별 실시간 측정정보 `getCtprvnRltmMesureDnsty` | 강원 지역 측정소 중 강릉 측정소의 미세먼지 등급 조회 |
| 4 | RunQ 자체 큐레이션 데이터베이스 | 강릉 러닝 코스, Finish Hub, 로컬 맛집·카페·명소를 직접 조사해 구축 |

> **러닝 적합도 판단 규칙** — 강수가 있으면 `우천 주의`, 미세먼지 등급이 나쁨 이상이면 `대기질 주의`, 그 외에는 `좋음`으로 표시합니다.

## 로컬 실행 방법

```bash
# 1. 저장소 클론
git clone https://github.com/wavlike/RunQ.git
cd RunQ

# 2. Android Studio로 프로젝트 열기 → Gradle Sync

# 3. API 키 설정 (아래 참고)

# 4. 에뮬레이터 또는 실기기에서 실행
./gradlew installDebug
```

> ⚠️ **API 키 필요** — 공공데이터포털에서 TourAPI · 기상청 단기예보 · 에어코리아 서비스 활용 신청 후 발급받은 **Decoding 인증키**와 Kakao Developers의 **네이티브 앱 키**가 필요합니다. 인증키는 `local.properties` 등 Git에 올라가지 않는 위치에 두고 커밋하지 마세요.

> ⚠️ **위치 권한** — GPS 트래킹과 Finish Hub 추천을 위해 `ACCESS_FINE_LOCATION` 권한을 허용해야 합니다.

## 성과 및 발전 계획

### 구현한 것

- ✓ 강릉 주요 관광지(경포호·안목해변 등) 기반 러닝 코스와 거리·난이도·지형 정보 제공
- ✓ 실시간 GPS 기반 러닝 트래킹과 완주 기록 저장
- ✓ Finish Hub를 통한 완주 지점 주변 맛집·카페·볼거리 연계
- ✓ 관광공사·기상청·에어코리아 공공데이터와 자체 로컬 큐레이션 결합

### 발전 계획

- 강릉에서 검증한 코스·Finish Hub 구조를 **속초·동해 등 강원권**으로 확대
- 러닝 기록과 이용 데이터를 기반으로 **개인화 코스 추천** 고도화
- 계절·축제·행사와 연계한 **상황별 러닝 코스 및 관광 추천** 강화
- 러닝 인증·코스 리뷰 등 **사용자 참여형 기능**으로 확장
